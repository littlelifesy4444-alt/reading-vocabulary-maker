
# Reading Vocabulary Maker

독해 지문을 복습해야 잘 풀 수 있는 단어장/시험지/해설지 생성 웹앱입니다.

## 핵심 규칙
- 지문 난이도와 어휘 밀도에 따라 단어 수 자동 조절
- 단어장: 단어, 발음, 품사, 뜻, 정확한 동의어/반의어, 새 예문
- 정확한 동의어·반의어가 없으면 `—`
- 단어장 예문은 시험에 재사용하지 않음
- 시험: 1(40%) / 2(30%) / 3(15%) / 4(15%)
- 1·2는 주관식 + 첫 글자 힌트
- 1은 원문 핵심 사실·상황·인과·대조 중 하나 이상 보존, 과도한 변형 금지
- 2는 새로운 문맥
- 3은 영영풀이 객관식
- 4는 정확한 동의어/반의어/어휘관계 객관식
- 시험 순서는 단어장 순서와 다르게 섞음
- 생성 후 전체 난이도 선택, 개별 문항 쉽게/어렵게 재생성
- Word 출력: 단어장 / 시험지 / 학생용 정답·해설
- 모든 Word 출력에 페이지 테두리 + 오른쪽 하단 `Hard work pays off.`

## 지원 파일
1차 버전: PDF, JPG, JPEG, PNG, WEBP

PDF 페이지 범위 입력 가능: `94-113`, `94,96-100`

## 로컬 실행
1. Python 3.11+ 설치
2. 폴더에서:
   ```
   pip install -r requirements.txt
   ```
3. 환경변수 설정:
   ```
   OPENAI_API_KEY=...
   FLASK_SECRET_KEY=아무_긴_랜덤문자열
   OPENAI_MODEL=gpt-5.6
   ```
4. 실행:
   ```
   python app.py
   ```
5. 브라우저에서 `http://localhost:5000`

## 배포
Render/Railway/Fly.io 등 Python 웹서비스에 올릴 수 있습니다.
Start command:
```
gunicorn app:app
```

API 키는 반드시 서버 환경변수에만 저장하세요. 브라우저 코드에 넣지 마세요.

## 중요한 운영 메모
- 큰 PDF는 필요한 페이지만 범위 지정하는 것을 권장합니다.
- OpenAI API의 PDF 입력은 텍스트와 페이지 이미지를 함께 처리할 수 있으므로 스캔/레이아웃 자료에도 유리하지만, 파일 크기와 토큰 비용이 증가할 수 있습니다.
- 현재 앱은 결과를 세션에 보관하므로 서버 재시작 시 결과가 사라집니다. 학생/시험 기록 누적 기능은 다음 단계에서 DB를 붙이는 것이 좋습니다.
